# data-antiques

Data repository for the **East Asian Antiques 東方古董** demonstration dictionary of the
[OpenCDD](https://github.com/opencdd) project.

- `reference-docs/examples/antiques.cddal` — the dictionary itself
  (single source; CDDAL plain text).
- `data/antiques/database.json` — browser JSON, generated by
  `rake browser:build` (unit references bound into the
  [IEC 62720](https://opencdd.github.io/d/iec-62720/) units dictionary,
  which is free in its entirety per the IEC CDD License Agreement §6).
- `units.json` — compact IEC 62720 unit index used for the binding
  (same §6 terms).

The curated corpus plus generated sections from The Metropolitan
Museum of Art Open Access API (CC0) — see the fixture header.
`rake browser:harvest_met` re-runs that harvest.

The engine is [opencdd-ruby](https://github.com/opencdd/opencdd-ruby)
— an implementation of working with OpenCDD data, used read-only here.
